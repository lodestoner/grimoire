Grimoire local source candidate

This unsigned Windows x64 package was built from the public source candidate.
There is no public binary release yet. A local build is not production certified.
Run Grimoire.exe to start the tray app and optional setup wizard. The installer
is per-user; Windows startup is opt-in. Uninstall retains settings and stored
credentials.

View releases opens the repository releases page in a browser, which may be
empty. Grimoire does not check an update feed, download executables or install
updates. Verify local package hashes against SHA256SUMS.txt before use.

The portable ZIP includes the executable, license and third-party notices.
Keep those files together. Unless a configured data folder is used, settings
live under your Windows roaming application data. Back up that folder and keep
your prior executable before testing. Quit from the tray before replacing a
portable executable. Credentials remain in Windows Credential Manager.

Local tools need no account. AI providers and integrations are optional. Codex
and Gemini CLI actions are temporarily unavailable until their selected-input
read boundary is verified; saved choices are retained and require an explicit
alternative provider. Remote integrations may permit plaintext HTTP and large
files can exhaust resources. Standard-user desktop behavior, focus, hooks,
SmartScreen and authenticated provider use need separate acceptance.
